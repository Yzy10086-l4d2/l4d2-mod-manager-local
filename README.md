# L4D2 MOD 管理工具 · 本地版

树状管理**本机**已装的求生之路 2 MOD：一眼看清每个位置当前用的是哪个，随时整套切换风格，不改动任何 vpk 文件（只写 `left4dead2\addonlist.txt` 的开关）。

> 跟**便携版**（另一个仓库）同一套界面和识别引擎，区别只有一条：便携版从 U 盘库复制文件进游戏，本地版直接管游戏目录里现有的东西。

## 状态

开发中。当前基线 = 便携版 2.62.6 的完整功能（树状位置、识别归类、工坊、翻译、多风格），正在把「U 盘库 / 复制装机 / 组件包 / 回收」这一整套剥掉，只留本机管理。

计划中的差别：

| 能力 | 本地版 |
|---|---|
| 树状分级、每个位置当前用了什么 | 有 |
| MOD 识别归类（枪械/人物/特感/药品/杂项…） | 有 |
| 多风格一键切换 | 有 |
| 创意工坊浏览 / 下载 / 自动改名 | 有 |
| 详情页 + 中文翻译 | 有 |
| 扫描 U 盘主库、从库复制、装机流程 | 没有（这是便携版的活） |

## 环境

Windows 10 / 11，自带 .NET Framework 4.x，不需要 SDK。

## 编译

```
build.bat
```

只用 Windows 自带的 `csc.exe`，不出网、不装包，产物是 `L4D2LocalSetup.exe`。
