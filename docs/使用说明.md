# 使用说明（本地版）

这份说明按「第一次打开 → 日常用」的顺序写，不需要懂技术。

> 对应版本：v0.5.0。这一版主界面重做过（三列 + 可拖分栏），按钮名也换了几处，
> 如果看到的小字和这里不一致，以程序为准并提个 issue。

## 一、第一次打开

1. 双击 `L4D2LocalSetup.exe`
   - Windows 可能弹 SmartScreen，点「更多信息」→「仍要运行」
2. 如果顶部「游戏目录」是空的，点右上 **设置** → 「自动找」；找不到就点「浏览…」，选到
   `...\steamapps\common\Left 4 Dead 2`（这一层里能看到 `left4dead2.exe`）
3. 主界面会自己列出来：游戏里现在装了哪些 MOD，按「能替换的东西」分好类

主界面是**三列**（窗口太窄时自动退回两列）：

```
┌────────────┬──────────────────┬──────────────┐
│  方案树     │  这个位置的候选    │  悬停详情     │
│ 枪械→AK-47 │  ● RGB-AK_2025   │  封面大图     │
│ 人物→比尔   │    l4nmk4{m16}   │  名字/体积    │
│ …          │    …             │  改了什么     │
└────────────┴──────────────────┴──────────────┘
```

- 左栏（游戏现状 / 日志）默认收着，需要时点开
- 三条竖线**可以拖**，拖动后的宽度会记住

## 二、看懂那张树

左边是一棵树，从上到下是「大类 → 小类 → 具体东西」：

```
枪械 → 步枪 → AK-47（4 个）
        …    → M16（3 个）
人物 → 一代 → 比尔（1 个）
杂项 → 特效 → 特效套装（6 个）
```

- 括号里的数字 = **这个位置库里/游戏里有几个候选**
- 数字是 0 的位置也会列出来 —— 那是在告诉你「这里还能装点什么」
- 点一个位置，中间列出它的所有候选；标题显示**当前用的是哪个**
- 鼠标划过任意一行，右边详情栏立刻换成那一条（封面 / 名字 / 体积 / 改了什么 / 作者）

## 三、换风格

1. 点中一个位置（比如 AK-47）
2. 中间点你想要的那一套
3. 点右下「**替换此方案**」

本地版这一步**不会复制、不会移动任何文件**，只把 `addonlist.txt` 里的开关改掉：
这套里有的打开，**这套里没有的全部关掉**（整套级语义，不是「只动这一个位置」）。
进游戏就是新外观。

想换回来：把原来那套再点一次、再替换一次即可。

> 注意：如果你只想「在现有基础上加一个东西」，别用「替换此方案」——
> 那会把不在这套里的都关掉。这种情况直接在那个位置的候选里挑，用「开启」列单独打开。

## 四、创意工坊

- 顶部「工坊」按钮：浏览、搜索、勾选要下的
- 下载会落到 `left4dead2\addons`
- 下完会自动读包里的 `addoninfo.txt`，按**游戏里显示的标题**改名
- 点一行看详情：介绍正文 + 中文翻译（翻译服务每天有免费额度，长文只翻前面几段）
- 想要封面图：下载后重新扫一次，程序会从包里读 `addonimage`

## 五、开关与卸载

- **开关**：在位置候选列表最右的「开启」列，勾上/取消，写的是 addonlist，不动物理文件
- **游戏开着时不会写**：会弹一句「游戏正在运行」。游戏退出时会把内存里的开关整份写回 addonlist，
  这时候写进去会被覆盖 —— 先完全退出游戏（不是最小化）再来
- **外部改动会被看出来**：每次写完会留一份快照。如果 Steam 更新订阅把 MOD 重新打开了，
  或者你在游戏里改过开关，切回窗口时状态栏会提示「检测到 addonlist 被外部改过：开启了 N 个 / 新增 N 个（举例）」，
  同一处只提示一次。想立刻同步就点「刷新游戏现状」
- **删除**：直接删 vpk 文件（删了就没了，不进回收站，自己确认好）；游戏开着时会被拦住

## 六、启动项（可选）

顶部「启动项」打开的是**只读清单**，按「推荐 / 可选 / 多余 / 别加」四组列好，每条都写了作用与依据
（是否有效是按本机游戏 exe/dll 搜字符串实测的）。勾选后底部会拼出组合串，点「复制」自己贴到
Steam → 库 → 右键游戏 → 属性 → 启动选项。

**程序不会替你改 Steam 的 `localconfig.vdf`。** 这一条是 v0.5.0 改的：以前会直接写文件，容易越界，去掉了。

## 七、常见问题

**Q：翻译只出来一小段？**
免费翻译接口按天限额度，长文翻到额度用完就停，剩下的显示原文。

**Q：工坊里有些物品下不了？**
「文件夹式」的物品没有直链，只能通过 Steam 客户端订阅。

**Q：L4N / Skeeto / dxvk 在哪装？**
本地版不做这些（不往游戏里复制任何东西）。需要组件包请用便携版。

**Q：改完进游戏没变化？**
先确认游戏完全退出后再进；开关是游戏启动时读的。如果修改时游戏正开着，程序根本不会替你写（会弹提示），
退出游戏后再改一次就行。

**Q：我明明点了一整套替换，别的 mod 怎么被关了？**
这是 v0.5.0 起的整套级语义：替换 = 只留这套。只想加料就用单位置的「开启」列。

**Q：为什么封面显示「包内无图」？**
多数包本来就没带 `addonimage`（实测 55 个 vpk 里只有 26 个有），属正常，不影响使用。

**Q：Steam 更新了 mod，或者我在游戏里改过开关，程序里显示的还是旧的？**
程序只读/写 `addonlist.txt`，外部改动它不知道——但每次写完会留快照，切回窗口时会提示一次
「检测到 addonlist 被外部改过」。想立刻对齐就点「刷新游戏现状」。
