# v0.6.44 发布说明

识别系统结构整改。正常使用无感；新增保护开关默认关闭。

## 改了什么

- **证据可追溯**：每个 MOD 的识别结论带证据（命中的模型/材质/图标/音效、匹配方式、置信等级），不再只有一句"规则:模型名"。
- **规则表统一**：识别表、别名表、特感表、幸存者表、药品规则合并到一处，改规则不用再靠插入顺序。
- **资源类型判定**：区分带模型的正常 MOD / 纯特效 / 纯音效 / 纯贴图 / 纯脚本。
- **EffectsOnlyVeto（默认关闭）**：开启后，纯特效包不再被误判成武器。110 个真实样本里修正 2 例、0 回归。
- **脚本类**：只有 .nut/scripts 的 MOD 归入「脚本 · 脚本」，不再落未归类。
- **多主体字段**：一个包换多个对象时记录主体列表（主件 + 附带件），界面仍显示主件。
- **修复**：散装 vpk 路径缺少的「多人生还者包」回落保护。

## 验证

- 110 个真实 U 盘样本，分类结果与 v0.6.41 逐行一致；
- 仅 3 个脚本包按设计改判为「脚本/脚本」；
- 构建与回归脚本：tools/ident_regress.sh。

## 安装

下载 L4D2LocalSetup.exe，替换旧 exe 即可；配置与用户分类不变。
