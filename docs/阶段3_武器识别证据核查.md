## 2. 影响面级误判（确定，主件正确）

现行输出把**官方世界模型**算成了另一把霰弹枪，多报「附带」，共 4 个包：

| 包名 | 包内模型（条目名） | 现行结果 | 期望结果 |
|---|---|---|---|
| `木喷\【Miku主题】官模木喷替换.vpk` | w_shotgun + v_pumpshotgun | 主体木喷，影响面「附带:**铁喷**」 | 木喷，**无附带** |
| `木喷\战痕印花集自由替换木喷.vpk` | w_shotgun + v_pumpshotgun1（内部名 v_pumpshotgun）+ v_pumpshotgun | 主体木喷，影响面「附带:**铁喷**」 | 木喷，**无附带** |
| `铁喷\[東方Project]⑨琪露诺⑨主题铁喷\3 …铁喷.vpk` | w_pumpshotgun_a + v_shotgun_chrome + tiepen（内部名 v_shotgun_chrome） | 主体铁喷，影响面「附带:**木喷**」 | 铁喷，**无附带** |
| `铁喷\火花铁喷半官方动作.vpk` | w_pumpshotgun_a + v_shotgun_chrome | 主体铁喷，影响面「附带:**木喷**」 | 铁喷，**无附带** |

**证据**：
1. 官方四格在包内是成对出现的世界模型 + 视角模型（`_probe/mdl.jsonl`）：木喷 = w_shotgun / v_pumpshotgun；铁喷 = w_pumpshotgun_a / v_shotgun_chrome；一代连喷 = w_autoshot_m4super / v_autoshotgun；二代连喷 = w_shotgun_spas / v_shotgun_spas。四个格子互不共用世界模型。
2. 按包内成对模型反推（也符合 L4D1 时代的世界模型命名习惯）：`w_shotgun.mdl` 属于 L4D1 泵动、即 L4D2 木喷；`w_pumpshotgun_a.mdl` 属于 L4D2 铬喷、即铁喷。两块「官模木喷替换」包带 w_shotgun、两个铁喷动作包带 w_pumpshotgun_a，方向一致。
3. `docs/阶段B1` §3 第 13/14 行记录的就是这两组：木喷包 {铁喷,木喷}→取木喷、铁喷包 {木喷,铁喷}→取铁喷。v_ 优先保住了主件，但「同件世界模型」被当成第二件，才有了假的附带。
4. 规则表注释「裸 shotgun = w_shotgun.mdl = 铁喷的官方世界模型」与包内事实相反：那条「裸 shotgun→铁喷」只对**材质目录** `materials/models/v_models/weapons/shotgun/` 成立（3 个铁喷材质包即此路径），对模型名 `w_shotgun.mdl` 不成立。
5. 一代/二代连喷两组没有这个问题（各包只带本格的 w/v）。

**风险边界**：主件因 v_ 优先仍正确；只影响「影响面」字段。潜在风险是**只带 w_ 世界模型、不带 v_ 的包会被判反**——110 包里暂时没有这种样本（所有枪械包都带 v_）。最终定案需用游戏 `pak01_dir.vpk` 核对两个世界模型名的归属；本次可访问范围内未找到 pak01，只能按包内成对模型 + L4D1 命名推断，方向一致。
**可复现**：是（上述 4 行在基线中稳定）。
