# v0.6.45 发布说明

界面清理、识别修正与程序图标。配置、分类和方案都保留；升级直接替换 exe。

## 改了什么

### 识别

- 木喷 / 铁喷的视角模型 + 世界模型成对出现时，世界模型不再另算一个主体；只带世界模型时的原有映射不变。
- 纯材质包同时命中多把武器时不再猜主体，改为标记为歧义并列出「影响:…」；单把武器材质、多特感材质的行为不变。
- 位置别名表去掉中文「脚本」，避免普通中文名被误归脚本类。

### 已装 MOD 开关

- 关窗时若有未写入的开关或顺序，提示「写入并关闭 / 放弃修改 / 取消」。
- 新增「清理关着的」按钮；窄窗口下提示文字自动让位。

### 窗口与图标

- 设置、下载管理、启动项、工坊改成自绘标题栏，保留拖动、四边拉伸和独立任务栏图标。
- 方案总览改为独立窗口，支持 Esc 关闭。
- 分类图标 18 → 20px；枪械小图标精简线条，小尺寸下更清楚。
- EXE 补上红底白字「MOD」图标，与顶栏徽标一致；`app.ico` 含 16–256 共 9 个尺寸。

### 旧界面清理

- 3D 桌面整套移除：桌面页、本地 Web 服务、three.js 资源及对应启动参数与自检项。
- 删除永久隐藏的「一键还原」与还原流程；底栏只留进度、停止和预检状态。
- 隐藏的游戏路径下拉改为普通字段；旧方案下拉与提示标签删除。
- 左栏「日志 / 游戏现状」卡片删除；「启动时自动回填」搬进设置 → 程序更新。
- 右键菜单的「库文件夹管理… / 识别压缩包内容」与「留原版」隐藏按钮删除。

### 外观

- 浅色主题移除，外观只剩石墨 / 蓝黑 / 暖黑三套深色底盘；旧配置里的 `system` / `light` 自动落到默认底盘。

### 稳定性

- 插件旧版本回填、重复 MOD 清理失败时，结果里明确写「未完成」和数量。
- 删除 MOD 时若 addonlist 摘除或插件状态同步失败，会带回失败原因。

## 验证

- 构建：`build.bat`（csc）通过，`FileVersion = 0.6.45.0`。
- CI 9 组全绿：`treeself` / `layoutself` / `recogself` / `addonself` / `dupself` / `safeself` / `workshopself` / `launchself` / `gallerself`。
- 补充 7 组全绿：`uitest` / `galleryui` / `langself` / `uipaint` / `uitheme` / `imgself` / `uisettings`。
- Release 附件由 GitHub Actions 从 tag 对应提交重新构建，校验值以附件 `L4D2LocalSetup.exe.sha256` 为准。

## 安装

下载 `L4D2LocalSetup.exe`，替换旧 exe 即可；配置与用户分类不变。
