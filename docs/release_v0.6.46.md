# v0.6.46 发布说明

方案树容器分级、Tank 石头识别和勾选落盘。配置、分类和方案都保留；升级直接替换 exe。

## 改了什么

### 方案树

- 平台、脚本从「一个位置」改成「一堆」容器：组内能同时开好几个，点一行是给它单独开关，不再互相顶掉。
- Tank 扔的石头挂到 Tank 下面，树上变成 僵尸 → 特感 → Tank → 石头；识别和开关仍按独立槽位算。
- 导出改用界面那一套排序，排查分类时两边顺序一致。

### 识别

- 新增「石头」位置：`concrete_chunk01a`、`concrete_spawnchunk`、`tank_rock` 和「坦克石头」等中文别名都能认出来；回归加了对应用例。
- 认不出的东西单独归「未识别杂项」，不再混进「其他杂项」。

### 方案总览

- 地图、平台、脚本这类容器的候选逐项列出来，不再只显示「第一张 +7」。
- 内嵌画布和独立窗口统一刷新：只开独立窗口时点候选不再空引用。
- 顶栏「已装」计数跟着勾选实时动。

### 修复

- 直接点 MOD 开关后立即落盘，关掉程序再开也保留（以前只靠自动同步）。

## 验证

- 构建：`build.bat`（csc）通过，46 个源文件，`FileVersion = 0.6.46.0`。
- 本地自检：`recogself` / `treeself`（含 `ovself`）/ `layoutself` 全部 0 失败。
- 推送 tag 后由 GitHub Actions 跑 9 组自检并从同一提交重新构建附件；任一组失败不会产出 Release。
- 校验值以附件 `L4D2LocalSetup.exe.sha256` 为准。

## 安装

下载 `L4D2LocalSetup.exe`，替换旧 exe 即可；配置与用户分类不变。
